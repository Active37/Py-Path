Install PyPath

Add PyPath to your device for a dedicated app window and quick access from your home screen or desktop.

Chrome or Edge on a computer
Choose the install icon in the address bar, or open the browser menu and select Install PyPath.

Android
Open the browser menu and choose Install app or Add to Home screen.

iPhone or iPad
In Safari, tap Share, then Add to Home Screen.

Install options depend on your browser. If you do not see one, try Chrome, Edge, or Safari on a supported device.
